# Documentation - Society Maintenance Tracker

Welcome to the documentation for **Society Maintenance Tracker**.

## Overview
This directory contains architectural guides, API specifications, database design documents, and user workflows.

## API Documentation
Interactive API documentation is automatically generated by FastAPI when running the backend server:
- **Swagger UI**: [http://localhost:8000/docs](http://localhost:8000/docs)
- **ReDoc**: [http://localhost:8000/redoc](http://localhost:8000/redoc)
- **OpenAPI JSON**: [http://localhost:8000/openapi.json](http://localhost:8000/openapi.json)

## System Architecture
- **Backend**: FastAPI app with Pydantic v2 schemas and SQLAlchemy 2.0 ORM.
- **Database**: PostgreSQL with Alembic migration scripts.
- **Frontend**: Single Page Application built using React, Vite, TypeScript, and Tailwind CSS.
