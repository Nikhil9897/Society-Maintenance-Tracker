Interactive API documentation is automatically generated by FastAPI when running the backend server:

- **OpenAPI JSON**: [http://localhost:8000/openapi.json](http://localhost:8000/openapi.json)

## 🏗️ Architecture Overview
- **Frontend Layer**: React 18 + Vite + TypeScript + Tailwind CSS + Three.js 3D Hero + Lenis Smooth Scroll + Recharts.
- **Backend API Gateway**: FastAPI (Python 3.10+) with Pydantic v2 schemas and SQLAlchemy 2.0 ORM.
- **Async Workers**: FastAPI BackgroundTasks for SMTP / SendGrid email dispatch and audit logging.
- **Database**: PostgreSQL (Production) / SQLite (Development) with Alembic migration version control.
